# UYA public level-name cross-reference

This file is a **public-source naming cross-reference**, not retail-native loader proof.

Public source: `chaoticgd/wrench` commit `e67ea46e5e60ec52a0c31fcde1e3f46b20aa4cfb`, `data/underlay/uya_levels.asset`.

Retail OBP evidence independently establishes that, for all 51 sampled slot-1 `0x60` headers, raw word `+0x08` equals the physical hidden-table index exactly. That makes the Wrench numeric level IDs a strong human-readable cross-reference for the same observed retail indices, while still preserving the distinction between public semantics and retail-native provenance.
