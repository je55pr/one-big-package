## Native-derived behavior and currently hosted boundaries

The initialization branch *priority* at `FUN_L06_002e8678` is carrier selector (`state 1`), hidden/respawn selector (`state 15`), authored path entrance (`state 3`), then ordinary roaming (`state 8`). A path source proceeds through `state 4` path traversal, `state 5` airborne transition, `state 7` landing and returns to 8. State-8 roaming selects a home-relative destination within 0.5 to 2 native units and refreshes its destination after a 45–75 native-tick counter or arrival within 0.05 units. The recovered native movement is conditional on Moby byte `+0x31`; the host offers a bounded, deterministic local-PRNG substitute for admitted ordinary Frogs, with an explicit `roamingAllowed` gate where the native byte is not yet available. Roaming can enter 9 when target acquisition is enabled, with an original 1-in-9 selector; 9 chases the target and enters attack `state 12`, sequence 5, when closer than two native units. Frames 10–15 of that animation double the forward displacement and dispatch a radius-0.333, damage-1 common attack helper. Attack contact is eligible throughout the window and coalesced after a successful hit until the next loop. State 10 is alternate approach, state 11 its animation-gated jump, state 13 retreat, state 16 grabbed. Damage helper `0x2e94f0` removes health-depleted actors when the lives selector is zero; otherwise decrements lives, resets source HP, returns to spawn and parks in `state 15` for a separate respawn trigger.

`Rac1FrogAuthored` parses selectors without combining them; `Rac1FrogSession` owns registration, per-actor source state, fixed authored identities, bounded movement, animation contact and damage lifecycle. `Rac1FrogContact` publishes a provenance-bearing class-827 player damage-1 envelope through normal damage transport and the existing Nanotech 77-tick protection. This is not a claim to have recovered the missing flags of the common `0x2599e8` attack helper. Exact native collision/contact joint, line-of-sight, common target acquisition, animation acceleration, random-state seed, ground probe and path geometry constraint solvers are **not** source-equivalent. Godot supplies an explicitly provisional capsule/LOS contact and `12`-unit target-admission policy, native-speed planar chase and swept-slide grounding. Deterministic local xorshift is a host substitute for the native PRNG seed and **must not** be mistaken for a replay-exact pattern.

Native carrier Frogs allocate one dynamic class-500 child (`0x1f4`) at the parent's transform and hide the Frog while remaining in state 1. The ten real LEVEL6 carrier placements (instances 391–393 and 461–467) all start in switch group zero with no fixed target. `Rac1FrogSession.BindCarrierChild` records successful source-owned class-500 creation; `OBPGame.Rac1FrogCarriers` clones the *retail* class-500 mesh and materials from an imported authored world crate but does **not** mint an authored class-500 instance, crate reward, save UID or hostile actor. Only a bound parent whose native global switch admits it can release at a target distance strictly under four native units, discard its owned child and transition state 1 to 8 with its original collision and visibility restored. The native `FUN_L06_002e9f30` burst now uses source fragment classes **357** for four pieces and **358/359** for eight more, with original spawn-offset, velocity and scale parameters interpreted through OBP's existing crate-debris host motion. Class 359 is decoded from the original LEVEL6 static class catalogue, not approximated with 358. The global native PRNG order, effect mixer and `allocate_voice_for_target_entry(4,0)` sound still differ from retail. Native `FUN_L06_002e94f0` checks a hit on the owned child *before* the parent's regular health logic; hits with missing source or source class other than **0xAF** burst the child and terminate the **parent Frog**, not release it into combat. This is implemented for the real animated wrench sweep against the child's retail mesh, including exact source class exclusion and source population protection. Other damage producers and a physically colliding standalone child Moby are not hosted yet; the mesh bounds remain a marked host contact approximation. Hidden/respawning Frogs need a separate source switch/life trigger; grabbed state 16 needs a distinct external Moby transition. These outstanding interactions remain parked rather than inventing activation. Fixed-target index 677 keeps its native identity, and the host will not retarget it at Ratchet when the referenced object is unavailable. Alternate state10/11 volume gate `+0x1ec` and exact state5/6 landing/collision fields also remain provisional. Death burst graphics/bolts for class 827 were not proven, so the host hides the terminated source without borrowing another family's reward or fragments.

## Tests and runtime verification

`Rac1FrogShuttleSwitchTests` adds authored shuttle volume transitions, switch-group exclusivity and malformed selector rejection, plus an optional retail ISO-backed check for class-1109 clip-volume selectors. `Rac1FrogSessionTests` now also verifies class-500 child ownership, rejection of wrong/duplicate child classes, strict four-unit proximity release, class-0xAF hit rejection, immediate parent termination on qualifying child hits, native shuttle gating, 4+8 debris source class identities, seeded bounds and no extra authored instances. It exercises short-selector precedence, path introduction, deterministic pursuit/attack-window event deduplication, fatal cleanup, source lives/state15 parking and owner-backed damage rejection. Its local retail-authority test parses **all 193 original source PVars** across LEVEL6 and LEVEL10, asserts exact group counts, original path records, HP and speed, and holds all initially hidden sources across 1,000 engine-neutral ticks to exclude accidental admission or over-spawn. This test skips without `OBP_RAC1_ISO`.

`tools/rac1-frog-smoke.ps1 -Level 6` (or `-Level 10`) boots the real level in Godot, verifies native census, path selectors and dormant noncollision. The LEVEL6 fixture verifies ten retail class-500 child visuals with hidden non-colliding source parents; performs the real host wrench sweep across the retail child mesh for **original instance 392**, proving source-owner termination and exactly 12 retail fragments with no bolts; then stages Ratchet within four units of **original carrier Frog instance 391**, proving state1-to-state8 release, child cleanup, collision handoff, no reward and no extra authored population. The newly released Frog also participates in the ordinary combat smoke. It additionally stages Ratchet in the retail class-1109 stop-1 volume, checks that alternate switch-gated Frogs activate with **both** contact layer and mask, then supplies an explicit returned-shuttle selection to verify the original population and contact masks are restored. It then stages one *original* ordinary Frog and Ratchet on an isolated synthetic floor to exercise the actual animated 60-Hz physics/gameplay dispatch, approach9, attack12/contact, ordinary Nanotech loss, an owner-backed wrench hit, terminal mesh and collision cleanup, and no excess source spawning. The placement of that one Frog and its flat encounter floor are **test setup**, not authentic world traversal. These gates do **not** prove that ordinary unmodified player input reaches and beats the same source encounter naturally, or that motion is frame-identical to PS2. Performance policy sleeps out-of-range Frogs beyond 30 Godot units while retaining the source identity; that limit is OBP-specific, not a native constant.
