# OBP brainstorming

> **NON-BINDING DESIGN MATERIAL**
>
> Everything in this directory is exploratory. These documents are **not** implementation specifications, roadmap commitments, native-behaviour claims, or promises that a particular idea will ship.

One Big Package is trying to discover what becomes possible when Ratchet & Clank (2002), Going Commando, and Up Your Arsenal stop behaving like three sealed games and instead become one cohesive game.

The purpose of this directory is to preserve useful cross-game design thinking without polluting the evidence-backed `research/` tree.

## Authority boundary

- `research/` describes what retail games, executables, data, and corroborating archaeology support.
- `docs/brainstorming/` asks what OBP *might* do with those recovered truths.
- Game-specific research branches should establish native facts.
- Cross-game design should remain reversible until archaeology and playtesting justify it.

If a brainstorming idea conflicts with retail evidence, the retail evidence wins for any claim about native behaviour.

## Working design principles

These are useful current instincts, not frozen rules:

1. **Preserve before remixing.** Native systems should be understood before OBP changes them.
2. **Fusion does not mean homogenisation.** Gadgetron and Megacorp, hoverboards and hoverbikes, different rare bolts, different arena identities, native fauna, and other game-specific concepts can coexist without being flattened.
3. **Old content should gain new meaning.** A later gadget should make previously visited worlds worth re-examining.
4. **Story faction does not equal entire planet population.** Invasions can layer over native ecology/history rather than erasing it.
5. **The galaxy should remain the star.** Hubs, arenas, VR, and mission systems should add reasons to travel, not replace the worlds with menus.
6. **Do not prescribe the final campaign order yet.** Original chronology is evidence, not automatically the final OBP structure.

Specialist branches should feel free to invalidate or refine any assumption here as better evidence arrives.
