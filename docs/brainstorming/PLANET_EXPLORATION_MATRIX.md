# Planet exploration matrix

> **NON-BINDING BRAINSTORM.** Scores below describe **design fit**, not claims that the original level already supports the mechanic. Specialist archaeology should correct location assumptions where needed.

The purpose of this matrix is to identify each world's natural exploration language before OBP starts adding routes. The goal is to avoid dumping every gadget onto every planet.

## Scoring

- **0** — little natural fit
- **1** — plausible supporting use
- **2** — strong fit
- **3** — defining/native-feeling fit

Columns:

- **W** — water / swimming / freeze-drain-fill potential
- **V** — verticality / aerial traversal
- **O** — large/open exploration
- **R** — grind-rail potential
- **G** — Magneboot / Gravity Boot surfaces
- **Q** — remote/small-space secrets: Visibomb, Spiderbot, Clank, etc.
- **E** — environmental manipulation: Hydrodisplacer, Thermanator, Dynamo, Tractor Beam, Refractor, etc.
- **L** — locks / disguise / infiltration

## Specialist non-planet destinations

These should not be forced into the same exploration template:

- Starship Phoenix — hub, VR, service/training secrets
- Slim Cognito's Ship Shack — specialist workshop/vendor location
- Maktar jamming array — station/low-gravity extension
- Dobbo / Damosel moon content — Giant Clank / scale-shift gameplay
- Wupash Nebula, Feltzin System, Deep Space Disposal, Gorn — ship-space activity rather than normal Ratchet traversal

## Water-state hit list

Planets where **Hydrodisplacer × Thermanator** style interactions appear especially promising:

| World | Why it fits | Example interaction idea |
|---|---|---|
| Hoven | Existing water manipulation + ice world | Move water into another chamber, freeze it, then climb/cross |
| Novalis | Waterworks, river, caves | Drain one reservoir, fill another, then freeze a new route |
| Pokitaru | Ocean/resort/waterfalls | Freeze surfaces or alter isolated resort infrastructure |
| Rilgar | Sewer/flood identity | Alter sewer levels, then freeze selected flooded corridors |
| Drek's Fleet | Water tanker | Late-game water-routing / freezing machinery |
| Oozla | Swamp/wetland | Manipulate pumps/channels; distinguish water from sludge |
| Barlow | Native Thermanator use | Add Hydrodisplacer so water-state puzzles become two-directional |
| Notak | Canal City | Redirect canal water into maintenance areas |
| Florana | Jungle/swamp | Wetland/temple routes |
| Aquatos | Water world + sewers | Major compound-gadget playground; manipulate bounded systems, not the ocean |
| Daxx | Docks/sea | Raise/freeze local water to expose docks/intakes |
| Quartu | Factory/coolant | Route industrial fluid, with material-specific rules |

## Candidate exploration hotspots

Working tiers for worlds that could support serious OBP Metroidvania expansion:

- **S:** Aquatos, Orxon, Hoven, Drek's Fleet, Boldan, Quartu, Aranos
- **A:** Novalis, Pokitaru, Rilgar, Kalebo III, Oozla, Endako, Barlow, Todano, Daxx, Marcadia, Thran Asteroid Belt
- **B:** Aridia, Batalia, Oltanis, Tabora, Joba, Smolg, Damosel, Florana, Kerwan/Metropolis
- **Specialist:** Umbris/Station Q9 for gauntlets; Grelbin/Tabora for open exploration; Phoenix for hub secrets

The purpose of tiers is to prompt future level-design discussion, not to rank the original levels.
